# Seaside Smashies

Website für den Smashburger-Laden an der Hauptstrasse 2 in Staad.

Reines HTML, CSS und ein kleines Skript. Kein Build, keine Abhängigkeiten, läuft direkt auf GitHub Pages.

- `index.html` – Inhalt, Karte und Preise
- `css/style.css` – Gestaltung
- `js/main.js` – Öffnungsstatus, Kategorie-Leiste, Karte auf Klick
- `assets/img` – Bilder, `assets/fonts` – Schrift Archivo (SIL Open Font License)

Öffnungszeiten stehen an zwei Stellen: in der Tabelle in `index.html` und oben in `js/main.js` (`HOURS`).
